# D-refactor round 3 (final): D4

Reviewed `app/gateway/router.py`, `app/gateway/auth.py`,
`app/integrations/bank/base.py`, `plaid_connector.py`, and
`plaid_webhook.py` — D4's full ~550-line diff — for duplication worth
consolidating, same restraint as rounds 1 (D1+D2: real duplication
found, extracted) and 2 (D3: nothing worth changing).

## Found and fixed

`router.py`'s three admin-gated endpoints (`link_account_page`,
`create_link_token`, `link_account_callback`) each repeated
`Annotated[str, Depends(require_admin)]` verbatim. Extracted as
`AdminUser` in `auth.py` — FastAPI's own documented idiom for reusable
`Annotated` dependencies, not a custom abstraction. `Depends` and
`Annotated` imports in `router.py` were then unused and removed.

No behavior change; purely a naming/reuse change at the type-annotation
level.

## Considered and left alone

`plaid_connector.py`'s `_get_decrypted_access_token` and
`_get_local_account_id_map` both open `self._engine.connect()` and run
one query, but the queries return different shapes (a single decrypted
string vs. a `dict` mapping) and have different empty-result handling.
Forcing a shared helper for one line of connection-open boilerplate
across two semantically distinct methods would add indirection without
real benefit — left as-is, matching the "don't manufacture
abstractions" bar every prior round has held to.
